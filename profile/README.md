## 1º Ano

Neste primeiro ano, o foco principal foi a construção da base lógica de programação, compreensão de arquitetura de computadores e os fundamentos do desenvolvimento web e design de interfaces.

### Disciplinas

*   **Computational Thinking with Python:** Foco no desenvolvimento do raciocínio lógico, resolução de problemas algorítmicos e fundamentos estruturais da programação utilizando a linguagem Python.
*   **Edge Computing e Computer Systems:** Introdução à arquitetura de computadores, sistemas embarcados e Internet das Coisas (IoT). Aborda a integração entre hardware e software utilizando linguagens como C++ e plataformas como Arduino.
*   **Front-end Design:** Estudo dos princípios de UI/UX (User Interface e User Experience), prototipação de interfaces e fundamentos de design visual aplicados a plataformas digitais.
*   **Web Development:** Desenvolvimento prático de páginas e aplicações web focadas no cliente (Client-Side), utilizando HTML5, CSS3 e Javascript para criar interfaces responsivas e dinâmicas.
